How it was made

Each island was baked as a block of chunks (z7 tiles for Iceland, z11 for Réunion) from Copernicus GLO-30 terrain and OpenStreetMap water, forest, roads and glaciers, with neighbours pasted into the margin so the seams continue. GDAL fixes the coordinates before the model paints, and a job whose output moves by one pixel is refused.

Each chunk is painted once at 1024 px, native two zoom levels below the opening view; every coarser zoom is downsampled from that one painting, so zooming in adds detail without redrawing the map.

This page replays finished bakes: no GPU runs here. The game built on these maps, a solo arena on an H3 hex grid, needs its server and is not part of this demo.
